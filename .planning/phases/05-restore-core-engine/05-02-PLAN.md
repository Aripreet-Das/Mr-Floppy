## What Was Done

1. **Chunked file restore architecture** — restore supported user files in 1 MB chunks via MTP/ADB, matching the chunked pull architecture from Phase 3:
   - Files copied from desktop backup folder to destination device via `adb push` or MTP `write`
   - Each chunk's SHA-256 computed on-the-fly during write (streaming hash update)
   - Chunk boundaries respected — no partial chunk write across boundaries

2. **SHA-256 verification pipeline**:
   - Streaming SHA-256 using `sha2` crate: `Sha256::update()` per chunk, `Sha256::finalize()` after last chunk
   - Per-chunk checksum compared against expected hash stored in restore manifest
   - Mismatch detection: chunk re-push + re-verify, or mark chunk as CORRUPT and log in manifest
   - Verification result (PASS/FAIL/MISSING) stored per chunk in manifest

3. **User-accessible destinations**:
   - Photos → `/sdcard/DCIM` / `/sdcard/Pictures`
   - Videos → `/sdcard/Movies` / `/sdcard/Android/Videos`
   - Audio → `/sdcard/Music` / `/sdcard/Android/Music`
   - Documents → `/sdcard/Documents`
   - Downloads → `/sdcard/Download`
   - User confirms target folder per category before restore begins

4. **Pre-restore disk-space check** (FR-031 continuation):
   - Estimated restore size computed from backup manifest `totalBytes`
   - Free space on destination checked via `adb shell df -k /sdcard`
   - If free space < estimated size, warning displayed (FR-031) and restore blocked until user acknowledges

5. **Integration with Tauri reactive watcher**:
   - `"file-restore-progress"` event emitted with: `{chunkIndex, chunkTotal, bytesThisChunk, checksumSoFar, status}`
   - `"file-restore-complete"` event emitted with: `{overallStatus, verifiedChunks, totalBytes}`
   - `"file-restore-error"` event emitted with: `{errorType, chunkIndex, context}`

6. **Frontend status display** (new component `src-components/RestoreProgress.tsx`):
   - Chunk-level progress bar with checksum status indicator per chunk
   - Overall transfer throughput (MB/s)
   - Estimated remaining time based on average chunk transfer rate
   - "Verify" button to re-check any chunk's SHA-256 against manifest
